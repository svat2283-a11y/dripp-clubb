# Dripp_Clubb — сайт магазину

Статичний сайт (GitHub Pages). Товари беруться з публічного магазину на Prom
(`scripts/scrape.mjs`) і оновлюються автоматично двічі на день (GitHub Actions).
Оформлення замовлень — через Prom.ua.

Оновити каталог вручну: вкладка **Actions → Update catalog from Prom → Run workflow**.
